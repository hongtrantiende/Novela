# Frontend Design
## Ground it in the subject
Name one concrete subject, its audience, and the page's single job.
## Design principles
- Display & Hero: Open with the most characteristic visual element of the subject.
- Typography personality: Pair display and body typefaces intentionally. Avoid neutral defaults.
- Structure is Information: Use structural cues only when we convey genuine sequential/logical meaning.
- Deliberate Motion: Rely on orchestrated transitions and load animations.
- Vision Complexity: Match the level of complexity to the creative vision.
## The Visual Design Process
1. Brainstorm: Sketch out a compact visual token plan covering Color (4-6 hex values), Type (2+ roles), Layout, and a signature visual element.
2. Explore & Critique: Compare the plan against generic templates. Refine any templated decisions before coding.
3. Build & Refine: Implement selector specificity cleanly and consistently. Follow the token plan exactly.
